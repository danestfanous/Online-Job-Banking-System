# **CareerCove**

This project is a semester-long group assignment for a Database Systems class, designed to showcase the integration of database management and a user-friendly graphical interface (GUI). The application is an online job board where recruiters and applicants can interact through a variety of features.

## **Features**

### **Applicant Features:**
- **User Account Management:** Sign up and log in to create and manage an applicant profile.
- **Application Tracking:** View pending job applications.
- **Job Search:** Browse available job openings.

### **Recruiter Features:**
- **User Account Management:** Sign up and log in to create and manage a recruiter profile.
- **Job Posting Management:** Post new job openings and manage existing listings.

### **Database Functionality:**
- **Core SQL Features:** Perform essential database operations such as creating, dropping, and populating tables.
- **Query Execution:** Execute queries to retrieve and manipulate data.

## **Technologies Used**
- **Database Management System:** SQL-based database to store and manage data.
- **Backend:** Java for database interaction and logic processing.
- **Frontend:** Java Swing for building the graphical user interface.
